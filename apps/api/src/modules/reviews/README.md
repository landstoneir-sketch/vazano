# Reviews module

این ماژول امتیاز معتبر خریدار به فروشنده را مدیریت می‌کند. هر استعلام فقط پس از انتخاب قطعی پیشنهاد می‌تواند یک امتیاز ۱ تا ۵ داشته باشد و فقط اعضای همان سازمان خریدار مجاز به ثبت آن هستند.

- امتیاز منتشرشده به استعلام، پیشنهاد منتخب و هر دو سازمان متصل است تا تعامل واقعی قابل اثبات باشد.
- امتیاز پس از ثبت قابل بازنویسی نیست؛ پشتیبانی می‌تواند با ثبت دلیل آن را پنهان یا دوباره منتشر کند.
- میانگین عمومی فقط از امتیازهای منتشرشده محاسبه می‌شود.
- ایجاد و تعدیل امتیاز در Audit Log ثبت می‌شود.
