# Suppliers

`GET /v1/suppliers/performance` شاخص‌های هر سازمان فروشنده عضو کاربر را به‌صورت tenant-safe برمی‌گرداند: فرصت‌های دریافت‌شده، نرخ پاسخ، برد، زمان پاسخ، اعتبار و وضعیت اشتراک. پاسخ فقط از عضویت‌های فعال موجود در Session ساخته می‌شود و شناسه سازمان از ورودی کاربر پذیرفته نمی‌شود.

این ماژول پروفایل، توانمندی، محدوده جغرافیایی و فرایند بررسی فروشندگان را مدیریت می‌کند. مالک یا مدیر فروشنده می‌تواند دسته‌های قابل‌تأمین و استان‌های خدمت‌رسانی را ثبت کند؛ هر تغییر پروفایل را دوباره به صف بررسی وازانو می‌فرستد.

ظرفیت تولید، حداقل سفارش و زمان آماده‌سازی به‌صورت توضیح متنی ثبت می‌شوند تا مدل به سنگ یا واحد اندازه‌گیری خاص محدود نشود. صدور فاکتور رسمی، ارائه نمونه و خدمات نصب نیز به‌صورت قابلیت‌های مستقل نگهداری می‌شوند و پس از تأیید در پروفایل عمومی نمایش داده می‌شوند.

پوشش جغرافیایی به شناسه‌های مرجع استان متصل است و نام استان فقط به‌عنوان Snapshot سازگار با سوابق قبلی نگهداری می‌شود. تطبیق استعلام از رابطه مرجع استفاده می‌کند و فقط در نبود شناسه مکان، برای داده‌های قدیمی به نام استان بازمی‌گردد.

مدارک هویتی، ثبتی و مجوزهای فعالیت از مسیر امن Attachments بارگذاری می‌شوند و در فضای Object Storage خصوصی قرار می‌گیرند. تأیید نهایی فروشنده در Backend بدون حداقل یک مدرک `READY` مجاز نیست؛ فایل قرنطینه‌شده، ردشده یا در انتظار اسکن برای تأیید قابل استفاده نیست.

شاخص عملکرد فروشنده تعداد و میانگین امتیازهای منتشرشده و متصل به خرید واقعی را نیز نمایش می‌دهد؛ امتیاز پنهان‌شده در محاسبه وارد نمی‌شود.

فهرست و پروفایل عمومی فقط سازمان‌های فعال با وضعیت `VERIFIED` را نمایش می‌دهد. مدارک احراز، اعضا، شماره تماس و اطلاعات مالی هرگز از API عمومی بازگردانده نمی‌شوند.
