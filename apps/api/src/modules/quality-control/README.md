# Quality Control

خدمت اختیاری کنترل کیفیت وازانو پس از انتخاب پیشنهاد فروشنده قیمت‌گذاری می‌شود. مبنای MVP مبلغ نهایی همان پیشنهاد و نرخ نسخه‌بندی‌شده ۳٪ (`300` basis points) است. مبلغ‌ها با `BigInt` و به ریال محاسبه می‌شوند.

انتخاب گزینه در RFQ فقط یک درخواست اولیه می‌سازد. پس از انتخاب فروشنده، وضعیت به `QUOTED` می‌رود و خریدار کارمزد محاسبه‌شده را از مسیر Adapter پرداخت می‌کند. فقط Callback تأییدشده سروربه‌سرور می‌تواند درخواست را به `ACCEPTED` ببرد و رسید قطعی بسازد؛ Callback تکراری موجب فعال‌سازی یا رسید دوم نمی‌شود. همه تغییرات حساس در Audit Log و Outbox ثبت می‌شوند.

کاربران دارای مجوز `quality_control.manage` صف عملیاتی را مدیریت می‌کنند. انتقال‌های مجاز MVP عبارت‌اند از `ACCEPTED → IN_PROGRESS → COMPLETED` و لغو مستدل از دو وضعیت اول؛ پرش یا بازگرداندن وضعیت مجاز نیست.
