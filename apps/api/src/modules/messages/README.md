# Messages module

گفت‌وگوهای این ماژول به یک استعلام و یک تأمین‌کننده دعوت‌شده محدود هستند. اعضای سازمان خریدار و همان سازمان تأمین‌کننده به گفت‌وگو دسترسی دارند و سایر تأمین‌کنندگان وجود یا محتوای آن را مشاهده نمی‌کنند.

- متن پیام حداکثر ۲۰۰۰ نویسه و بدون HTML است.
- پیام‌ها حذف یا ویرایش نمی‌شوند تا سابقه تعامل قابل ممیزی باقی بماند.
- وضعیت خواندن برای هر کاربر و در سطح گفت‌وگو نگهداری می‌شود.
- ارسال پیام یک رویداد Outbox تولید می‌کند تا اعلان بدون وابستگی مستقیم به سرویس پیام‌رسانی ساخته شود.
