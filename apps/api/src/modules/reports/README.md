# Reports module

این ماژول نمای خواندنی و تجمیعی عملیات MVP را برای مدیران مجاز فراهم می‌کند. شاخص‌ها مستقیماً از داده‌های عملیاتی محاسبه می‌شوند و شامل قیف استعلام، عرضه و تقاضا، اشتراک، درآمد موفق، کنترل کیفیت، قرارداد و دسته‌های پرتکرار هستند.

این پیاده‌سازی برای حجم MVP مناسب است. با رشد داده، همان قرارداد API باید روی Read Replica، جدول‌های تجمیعی یا انبار داده منتقل شود تا بار گزارش‌گیری از دیتابیس تراکنشی جدا شود.
