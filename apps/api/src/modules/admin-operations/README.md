# Admin operations module

این ماژول ابزارهای عملیاتی حساس مدیر را از تنظیمات تجاری جدا نگه می‌دارد: مشاهده کاربران، تعلیق و فعال‌سازی حساب، لغو همه نشست‌ها، مرور Audit Log و رسیدگی به رخدادهای امنیتی.

- شماره موبایل در پاسخ‌های فهرستی ماسک می‌شود.
- تعلیق کاربر تمام نشست‌های فعال او را لغو می‌کند.
- مدیر نمی‌تواند حساب خودش یا آخرین مدیر ارشد فعال را تعلیق کند.
- تمام اقدامات مدیریتی همراه دلیل در Audit Log ثبت می‌شوند.
- OTP، Token، Cookie و Secret در هیچ پاسخ یا Log ذخیره نمی‌شوند.
