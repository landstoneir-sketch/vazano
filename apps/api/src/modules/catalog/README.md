# Catalog module

مرجع داده‌محور حوزه‌ها، دسته‌بندی‌ها، واحدهای اندازه‌گیری و ویژگی‌های فنی محصول است.

- `ProductAttributeDefinition` تعریف مشترک ویژگی، نوع داده، گزینه‌ها و قواعد اعتبارسنجی را نگه می‌دارد.
- `CategoryAttribute` ویژگی را با ترتیب و الزام قابل تنظیم به یک دسته متصل می‌کند.
- `GET /v1/catalog/categories/:categoryId/attributes` قرارداد فرم پویا را در اختیار رابط کاربری می‌گذارد.
- Backend هنگام ثبت استعلام، مقدار ویژگی‌ها را مستقل از Frontend و مطابق Binding دسته اعتبارسنجی می‌کند.
- مسیرهای `/v1/admin/catalog/*` با مجوز `category.manage` ایجاد و ویرایش دسته‌ها، تعریف ویژگی‌ها و اتصال آن‌ها را فراهم می‌کنند.
- دسته و ویژگی استفاده‌شده حذف فیزیکی نمی‌شود؛ غیرفعال‌سازی سوابق استعلام‌های قبلی را حفظ می‌کند.
- کد دسته، کد ویژگی و نوع داده ویژگی پس از ایجاد ثابت‌اند تا قرارداد داده تاریخی شکسته نشود.
- ایجاد، ویرایش و تغییر اتصال ویژگی‌ها در `AuditLog` ثبت می‌شود.
- واحدهای اندازه‌گیری نیز از همان پنل با کد پایدار، نماد، دقت اعشار و غیرفعال‌سازی غیرمخرب مدیریت می‌شوند.

برای افزودن مصالح جدید، دسته و Bindingهای آن باید از Seed یا صفحه `/admin/catalog` ثبت شوند؛ منطق RFQ به نوع خاصی از سنگ وابسته نیست.
