# Support module

این ماژول تیکت پشتیبانی و گزارش تخلف MVP را مدیریت می‌کند. تیکت عادی فقط برای ثبت‌کننده قابل مشاهده است؛ کاربران دارای مجوز `support.manage` صف رسیدگی را می‌بینند و می‌توانند وضعیت، اولویت، نتیجه و یادداشت داخلی ثبت کنند.

- گزارش امنیت یا حریم خصوصی به‌طور خودکار P1 می‌شود.
- شکایت، گزارش تخلف و اعتراض به‌طور خودکار P2 می‌شوند.
- یادداشت داخلی هرگز در API کاربر عادی بازگردانده نمی‌شود.
- تغییر وضعیت و عملیات حساس در Audit Log ثبت می‌شوند.
- پرونده حقوقی و داوری کامل خارج از محدوده MVP است.
