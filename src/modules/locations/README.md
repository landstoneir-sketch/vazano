# Locations

مرجع قابل‌ویرایش استان و شهر برای فرم‌های استعلام و توسعه‌های آینده است. API عمومی فقط رکوردهای فعال را برمی‌گرداند؛ تغییرات مدیریتی به مجوز `location.manage`، کنترل هم‌زمانی و Audit Log نیاز دارند.

نام استان و شهر هنگام ثبت استعلام به‌عنوان Snapshot نیز ذخیره می‌شود تا تغییرات بعدی در داده مرجع، سوابق تجاری را مخدوش نکند. حذف فیزیکی در MVP انجام نمی‌شود و رکوردها فقط غیرفعال می‌شوند.
