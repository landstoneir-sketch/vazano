# Quality Control

خدمت اختیاری کنترل کیفیت وازانو پس از انتخاب پیشنهاد فروشنده قیمت‌گذاری می‌شود. مبنای MVP مبلغ نهایی همان پیشنهاد و نرخ نسخه‌بندی‌شده ۳٪ (`300` basis points) است. مبلغ‌ها با `BigInt` و به ریال محاسبه می‌شوند.

انتخاب گزینه در RFQ فقط یک درخواست اولیه می‌سازد. پس از انتخاب فروشنده، وضعیت به `QUOTED` می‌رود و خریدار باید مبلغ خدمت را جداگانه تأیید کند؛ این تأیید به معنی برداشت خودکار وجه نیست. همه تغییرات حساس در Audit Log و Outbox ثبت می‌شوند.
