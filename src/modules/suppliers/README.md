# Suppliers

این ماژول پروفایل، توانمندی، محدوده جغرافیایی و فرایند بررسی فروشندگان را مدیریت می‌کند. مالک یا مدیر فروشنده می‌تواند دسته‌های قابل‌تأمین و استان‌های خدمت‌رسانی را ثبت کند؛ هر تغییر پروفایل را دوباره به صف بررسی وازانو می‌فرستد.

پوشش جغرافیایی به شناسه‌های مرجع استان متصل است و نام استان فقط به‌عنوان Snapshot سازگار با سوابق قبلی نگهداری می‌شود. تطبیق استعلام از رابطه مرجع استفاده می‌کند و فقط در نبود شناسه مکان، برای داده‌های قدیمی به نام استان بازمی‌گردد.
